# LAN Toolkit

面向弱电施工、智能建筑和网络调试人员的 Windows 局域网设备发现与统一调试入口。覆盖视频监控、可视门铃/对讲、门禁、网络设备、报警和智能楼宇等联网设备；具体识别能力取决于设备公开的协议和响应。

## 当前已实现

- PySide6 中文桌面界面；自动读取 IPv4 网卡、掩码、网关和当前网段
- 手动输入单 IP、CIDR 或起止 IP 范围
- 可取消的多线程 TCP 服务探测，并用 Windows SendARP 主动发现局域网设备、ARP 表补充地址信息（不依赖 ICMP）
- 固定线程池和有限任务队列；默认 16 个工作线程，最高 64，避免每个 IP 重复创建线程池
- ARP 表每轮只读取一次；常见 TCP 探测连接超时缩短到 120ms
- 随程序离线携带 IEEE MA-L/MA-M/MA-S 厂商登记 CSV（约 5.3 MB）；随机 MAC 单独标记，不误报厂商
- HTTP/HTTPS/RTSP、厂商服务、门禁/考勤、打印、NAS、Windows 文件服务等 TCP 特征检测
- 初步产品类别线索：视频设备、家庭网关、门禁/考勤、打印机、NAS、网络设备、电脑/文件服务设备、隐私随机 MAC 终端
- 保守的设备分类、离线 OUI 厂商识别与置信度；仅有单一端口特征时不会断言它是摄像头、门铃或门禁
- 设备详情、打开 HTTP/HTTPS、扫描进度和 CSV（UTF-8 BOM）导出
- SQLite 历史数据基础表已预留

## Windows 运行

1. 安装 Python 3.11 或更高版本。
2. 双击 `run.bat`，它会建立 `.venv`、安装依赖并启动程序。
3. 若 Windows 防火墙询问权限，仅在你有权管理的现场局域网中允许必要访问。

## 打包 EXE

在项目目录双击 `run.bat` 完成依赖安装后，再双击 `build_exe.bat`。产物位于 `dist\\LAN-Toolkit\\LAN-Toolkit.exe`。当前环境未直接生成 EXE，因为 EXE 打包需要 Windows 本机 Python 环境和依赖安装。

## 测试

```powershell
python -m unittest discover -s tests
```

真实局域网测试：将电脑接入有权管理的交换机，确认网卡和网段无误，先用小范围（例如 `192.168.1.1-192.168.1.20`）测试，再扫描整个 CIDR。默认并发为 16，可调低以减轻工作电脑负载。扫描时间取决于网段大小、设备响应和防火墙策略；低超时适合现场快速盘点，但慢速设备可能漏报。用已知设备的后台、MAC 和端口对照结果。

## 已知限制与后续

第一版尚未实现 ONVIF SOAP 信息读取、RTSP 鉴权/预览、门禁/门铃/楼宇厂商协议、Excel、扫描差异、IP 冲突检测、真实 LLDP/SNMP 拓扑和设备网络配置。当前统一调试入口提供后台访问；更多统一协议能力会逐类补齐。IEEE MA-L 登记可识别 MAC 分配组织，但不能单独证明设备具体产品型号；未知或随机 MAC 应保留为未知。扫描功能仅适用于用户有权管理的本地网络，不包含互联网范围扫描、密码绕过或破解。
